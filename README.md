## View it

Open `portfolioo/rajankumar.html` in any browser.

To publish it with GitHub Pages, go to **Settings → Pages**, choose **Deploy from a branch** with `main` and the root folder. The page is then served at `https://rajgenstack.github.io/portfoliowebsite/portfolioo/rajankumar.html`.
